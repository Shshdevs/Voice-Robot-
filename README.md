# Голосовое управление для Unitree Robotics

## Техническая справка: RobotCommand Mapper

### Назначение

Маппинг между доменной моделью `RobotCommand` и строковыми командами (голосовое управление /
API-эндпоинты).

#### Модель RobotCommand

Доступные команды робота-собаки:

- `Praying` — молитва
- `LayDown` — лежать
- `Barrel` — бочка
- `Dance` — танцевать
- `Heart` — сердечко
- `JumpLeft` — прыжок влево
- `JumpRight` — прыжок вправо
- `Paw` — дать лапу
- `Recover` — восстановление
- `Show` — шоу
- `SitDown` — сидеть
- `StandUp` — стоять
- `Stop` — стоп

**Пример:** `"танцуй"` → `RobotCommand.Dance`

## Поддерживаемые голосовые фразы (RU)

| Голосовые команды         | RobotCommand |
|---------------------------|--------------|
| молись, мольба            | Praying      |
| лежать, ложись            | LayDown      |
| бочка                     | Barrel       |
| танцуй, танец, танцевать  | Dance        |
| сердце, сердечко          | Heart        |
| влево, налеов             | JumpLeft     |
| вправо, направо           | JumpRight    |
| лапа, лапу                | Paw          |
| упал, заново              | Recover      |
| шоу, представление        | Show         |
| сидеть, сядь              | SitDown      |
| встань, поднимись, стоять | StandUp      |
| стоп, остановись          | Stop         |

## Примечания

- При нераспознанной голосовой команде возвращается `null`
- Эндпоинт ожидает строковые значения (`pray`, `lay_down` и т.д.)
